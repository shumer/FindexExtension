## New in 0.1.2

- Choose which Finder commands appear. Hide individual path formats, move commands,
  the hidden-file command and templates you do not use. Hidden templates stay on disk.
- Pin up to 20 favorite move destinations, give them short labels and arrange their
  order. Favorites appear before recent folders without duplicate destinations.
- Check the Finder extension, background helper connection and optional permissions
  on the new Setup page. Repair buttons connect the helper or open the relevant settings.
- Existing preferences are preserved. Missing favorite folders stop the move without
  sending files to another destination.
- The README now includes English screenshots, installation instructions, first steps
  and answers to common questions.

## Install or update

1. Download the universal DMG for Apple Silicon and Intel, requiring macOS 14 or later.
2. Open it and drag FinderPack to Applications. For an existing installation, use
   About > Check for Updates in FinderPack instead.
3. Launch FinderPack from Applications, then use Setup to enable its Finder extension
   and connect the background helper if this is your first installation.
4. Open Menu to choose commands or Favorite Folders to pin a destination. Changes
   appear in new Finder menus within five seconds.

The application and disk image are Developer ID signed, notarized and stapled.
Release assets include the signed Sparkle update archive, checksums and build metadata.

Runtime verification covers Apple Silicon on macOS 26.6.2. Intel and other supported
macOS versions still require broader runtime acceptance.
