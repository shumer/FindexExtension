# README screenshots

Settings screenshots were captured from the installed FinderPack 0.1.1 development build 14 on 2026-09-19,
using the English interface on macOS 26.6.2. These are actual application-window
captures, without compositing, retouching or generated UI.

- `menu-settings.png`: command group visibility and ordering.
- `templates.png`: the built-in Markdown template in the editor.
- `setup.png`: extension, helper and optional permission status.

These screens show the interface included in v0.1.2.
The maintainer supplied `finder-context-menu.png` on 2026-09-19. It shows the Russian
Finder file context menu in a demo folder and is included without further edits.

Keep settings screenshots in English. The Finder context screenshot may use Russian.
When replacing these images, use sample content
and check that no personal paths, file history, credentials or unrelated applications
are visible.
